Код на Python 3.11.
Веб-фреймворк - FastAPI; альтернативные фреймворки не вводить без ADR.
Хранение - SQLAlchemy, база - PostgreSQL; схема БД меняется только через Alembic-миграции.
ORM-модели объявляются в аннотированном стиле SQLAlchemy 2.0 (`Mapped[...]` + `mapped_column(...)`), а не присваиванием `Column(...)`. Иначе тип поля виден проверяльщику типов как объект колонки, и вся работа с моделью в сервисах и репозиториях перестаёт проверяться.
Тесты - pytest (основной раннер).

Статическая проверка типов - mypy, конфигурация в `mypy.ini` в корне, покрывает пакет приложения (не тесты). Прогон должен быть чистым.

Каждая функция и метод в приложении обязаны иметь аннотации всех параметров и возврата (`disallow_untyped_defs`, `disallow_incomplete_defs`). Причина не в единообразии: непроаннотированная сигнатура отдаёт вызывающему коду неопределённый тип, и проверка глохнет по всей цепочке дальше, а не только внутри самой функции.

Возврат неопределённого типа из типизированной функции считается ошибкой (`warn_return_any`) - это ловит места, где внешние данные (разбор JSON, ответы сторонних сервисов) уходят вглубь кода без проверки.

Тип возврата хендлера обязан совпадать с моделью ответа, объявленной в декораторе маршрута. Два источника правды о форме ответа расходятся молча.

Подавления - точечные, с указанием кода правила и комментарием, почему подавлено, а не отключение правил целиком и не подавление на весь файл.
