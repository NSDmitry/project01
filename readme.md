# Book Club API

Backend-сервис для книжного клуба на `FastAPI`.

Проект решает базовые задачи книжного клуба:
- регистрация и авторизация (пароль или Telegram), пользовательский профиль;
- книжные клубы: членство, приватность и роли, жанры, обложки;
- треды и комментарии внутри клубов;
- совместное чтение: заходы с этапами и прогрессом участников, выбор следующей книги голосованием;
- поиск книг через Google Books;
- Telegram-уведомления о событиях клуба и дедлайнах.

Репозиторий содержит монолит (`app/`) и отдельный сервис доставки уведомлений (`notification_service/`) со своей БД - подробнее в [Структуре проекта](docs/architecture.md).

## Стек

`Python 3.11`, `FastAPI`, `SQLAlchemy`, `PostgreSQL`, `Alembic`, `Redis`, `MinIO/S3`, `Docker Compose`, `Prometheus`.

## Быстрый старт

```bash
docker compose up --build
```

Сервис поднимется на [http://localhost:8000](http://localhost:8000).

Локальный запуск без Docker (после установки зависимостей и `.env` - см. [docs/setup.md](docs/setup.md)):

```bash
./run.sh
```

Накатывает миграции (`alembic upgrade head`) и поднимает `uvicorn` с `--reload`.
